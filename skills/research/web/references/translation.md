# Translation of foreign-language sources

When a source is in another language, translate what the report needs — never the whole document by default. The goal is an accurate, attributable quote or paraphrase in the report's language.

## Workflow

1. Fetch the source text (see the `web`/`doc` skill); keep the original file as the source of record.
2. Identify the passages actually needed (claims, numbers, definitions) — translate those, not filler.
3. Translate meaning, not word order; keep the register of the original (technical stays technical).
4. Mark every translated passage: `(translated from <language>)` on first use per source.

## Rules

- **Numbers, units, dates, names, and URLs are copied verbatim** — never re-derived or rounded during translation.
- Ambiguous terms: keep the original in brackets on first use — e.g. `Rechtsstaat [rule of law]`.
- Idioms without a direct equivalent: translate the meaning; if the exact wording matters, quote the original alongside.
- Never smooth over hedging: "may", "suggests", "preliminary" stay tentative in the translation.
- Machine translation is acceptable for orientation; quotes and load-bearing claims must be checked against the original wording — disclose when a passage was machine-translated and unverified.
- Cite the original source (URL/DOI), not the translation; a translation is a rendering, not a new source.
- For disputed passages (legal, medical, political), translate conservatively and, when possible, note that a certified translation should be consulted.
