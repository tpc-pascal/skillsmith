# Confirm report requirements — 4-group question table

**Trigger:** the user asks to create or rewrite a report; extraction/conversion-only requests do not trigger it.

Before in-depth research or drafting, ask once, up to four questions — one combined question per missing group, and only ask for missing information:

|Group|Required questions|
|---|---|
|**Requirements**|Who reads the report and why? Minimum page count/length? Language (Vietnamese / English / bilingual)? Submission format (`.md` / `.docx` / `.pdf`)?|
|**Structure**|Report form: international-standard or Vietnamese public-facing? Main sections/chapters? Cover, metadata, references list?|
|**Content**|Source scope (which files, which sections)? Which parts must include code / demos / diagrams / tables? Which parts to skip? May outside sources be added?|
|**Knowledge**|Depth level (general / specialist / academic)? Which sections may use `[standard knowledge]` to extend beyond the sources?|

- Do not re-ask what is already stated in the request/conversation. If the user delegates decisions, choose a suitable option and briefly state assumptions that affect the result.
- Do not block on nonessential details or require a detailed outline before reviewing the sources.
- Extract with the relevant skill, then write using exactly one `paper` format.
